# Risk Today - Streamlit apps

This folder is the public deployment package. It contains only the two Streamlit entry points and their required logos.

## Streamlit Cloud

Create one app for each file and use this folder as the repository root:

- `monitora-app.py`
- `risco_hoje-lab.py`

The apps retrieve rainfall, tide, and soil-moisture data from the configured remote services. Local history is intentionally ignored because Streamlit Cloud storage is ephemeral.
